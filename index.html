網頁轉 PDF 書籤

把這顆按鈕拖到書籤列：

📄 轉成 PDF

用法

  1. 打開有一頁一頁圖片的網頁（閱讀器、簡報、掃描檔…）
  2. 按書籤 → 自動從頂端捲到底，邊捲邊抓頁面（按 Esc 可提早停止）
  3. 右上角顯示「找到 N 頁」→ 確認 → 下載 PDF

偵測規則

  • 抓頁面上顯示寬高 ≥150px、原始尺寸 ≥300px 的 <img> 和 <canvas>
  • 自動找出真正會捲動的區塊（整頁或閱讀器內框）
  • 捲動時就先存下每頁，閱讀器把看過的頁面移除也沒關係
  • canvas 等畫完才收；內容相同的頁面只收一次
  • 頁面不能捲時，會問要不要自動按 → 翻頁
  • PDF 由書籤內建程式產生，不載入任何外部程式、不連外網
  • 圖片跨網域抓不到時，可選列印視窗「另存為 PDF」或只輸出抓得到的頁面

注意

  • 書籤裝好後不會自動更新，改版要回這頁重新拖一次
  • 程式全部在你的瀏覽器裡執行，不連任何外部網址、不上傳資料
  • 原始碼：github.com/DoDoSomeThing/page2pdf

抓不到的情況

  • 內容在跨網域 iframe 裡
  • 頁面是 CSS 背景圖或純文字
